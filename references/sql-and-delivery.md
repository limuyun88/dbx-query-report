# SQL 与交付规范

## SQL 预览

每次预览给出完整 SQL，而非片段。注释说明业务问题、实际连接和库表、结果粒度、期间与日期字段、金额/数量公式、状态与区域、NULL 与退款、结果上限及是否已执行。尚未核实的年份、字段、状态码或币种标为待确认；含占位符的 SQL 标为不可执行。按实际数据库方言写语法。

日期优先使用左闭右开区间。环比按（本期－上期）/上期计算，分母为零时返回 NULL 或“不可计算”；合计环比用合计值重新计算。百分数 SQL 乘100时在字段名标明百分号，Excel 百分比格式存小数比例。无记录、NULL 和真实零不能混用。不能把被工具截断的行当完整结果。

## 输出目录

在用户指定目录或当前项目下新建 `yyyy-MM-dd_主题-01`，已有同名目录则递增序号，不覆盖。三件套文件保存在该目录；输入 JSON、校验脚本及截图放在 `_制作与校验` 子目录。此目录仅存本次交付，不应复制到公开的技能仓库。

## 文件内容

- Excel：全部返回分组，数值按数值保存，保留 NULL 语义；仅对可加指标求和，客户去重数不得跨月相加。通用导出脚本生成每组结果一个工作表，不添加未经 SQL 或用户确认的业务合计。
- HTML：单文件离线可读，图表从同一结果生成，附精确数值表格和口径；窄屏可滚动，不依赖 CDN。
- SQL：UTF-8，保留获批并执行的完整 SQL 与业务注释；不得静默改口径。

检查文件存在且非空、Excel 可解析、数据行数和 Decimal 金额与 DBX 结果一致、HTML 文本转义与手机宽度、SQL 与批准版本一致。若无浏览器或 Excel/WPS 实测，只说明实际检查，不宣称已实测。
